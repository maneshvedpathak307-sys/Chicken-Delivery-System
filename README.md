# FreshNest - Chicken Delivery System

A full-stack chicken delivery web application built with
React, Spring Boot, and MySQL.

## Technologies Used

### Frontend
- React
- JavaScript
- HTML and CSS
- Axios

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Maven

### Database
- MySQL

## Project Structure

Chicken-Delivery-System/
├── backend/
├── frontend/
├── .gitignore
└── README.md

## Features

- User registration and login
- Product browsing
- Shopping cart
- Order management
- Customer profile management
- Admin dashboard and reports

## Prerequisites

- Java 21
- Node.js and npm
- MySQL
- Git

## Backend Setup

1. Create the required MySQL database.
2. Configure database credentials and JWT secrets
   using environment variables.
3. Open the backend folder.
4. Run the application using Maven.

## Frontend Setup

1. Open the frontend folder.
2. Run `npm install`.
3. Configure the backend API URL.
4. Run `npm start` or the appropriate command
   defined in package.json.
